# PRD: Highend Fashion Mall

## 1. Overview

### 1.1 Product Vision
프리미엄 럭셔리 브랜드를 큐레이션하여, VIP 고객에게 개인화된 쇼핑 경험을
제공하는 하이엔드 패션 이커머스 플랫폼.

일반 이커머스와의 핵심 차별점: **에디토리얼 큐레이션 + AI 기반 퍼스널 스타일링 +
VIP 등급별 맞춤 서비스**

### 1.2 Target Users

| Persona | Description | Needs |
|---------|-------------|-------|
| **VIP 고객 (Platinum)** | 연간 $50K+ 소비, 개인 스타일리스트 기대 | 1:1 큐레이션, 우선 접근, 전담 서비스 |
| **VIP 고객 (Gold)** | 연간 $15K-$50K, 브랜드 충성도 높음 | 얼리 액세스, 개인화 추천, 프리미엄 CS |
| **일반 고객 (Silver)** | 연간 $3K-$15K, 럭셔리 입문/탐색 | 발견의 경험, 브랜드 스토리, 시즌 프리뷰 |
| **브랜드 파트너** | 럭셔리 브랜드 담당자 | 브랜드 이미지 보존, 판매 데이터, 고객 인사이트 |
| **내부 운영팀** | MD, CS, 마케팅 (10명 규모) | 효율적 상품 등록, 캠페인 관리, 리뷰 관리 |

### 1.3 Success Metrics

| Metric | Target | Measurement |
|--------|--------|-------------|
| VIP 고객 유지율 | 85%+ | 분기별 재구매율 |
| 평균 주문 금액 (AOV) | $1,500+ | 월간 평균 |
| 추천 전환율 | 8%+ | 개인화 추천 클릭 → 구매 |
| 상품 등록 시간 | 10분 이내 | AI 파이프라인 소요 시간 |
| 리뷰 응답률 | 100% | 24시간 이내 응답 |
| NPS | 70+ | 분기별 설문 |

## 2. Core Features

### 2.1 F1: 럭셔리 상품 카탈로그 (UC-ECOM-01)

**목표**: 럭셔리 브랜드 상품을 고품질로 큐레이션하여 자동 리스팅

**사용자 스토리**:
- 운영팀이 원본 상품 데이터를 업로드하면, AI가 검증/정규화/콘텐츠 생성/QA를
  자동 수행하여 퍼블리시 가능한 리스팅을 생성한다
- 고객이 상품 페이지에서 에디토리얼 수준의 설명, 브랜드 스토리, 소재 정보를
  확인할 수 있다

**핵심 기능**:
- 상품 데이터 검증 (브랜드 인증, 가격대 검증, 이미지 품질)
- AI 기반 프리미엄 콘텐츠 생성 (SEO 최적화 + 럭셔리 톤)
- 브랜드별 보이스 가이드라인 적용
- 카테고리 자동 분류 (bags, rtw, shoes, accessories, jewelry, beauty)
- QA 게이트 통과 후 자동 퍼블리시

**Agent 매핑**: `luxury-product-curator` → `luxury-content-creator` → `luxury-qa-guardian`

### 2.2 F2: VIP 개인화 추천 (UC-CUSTOM-01)

**목표**: 고객 취향 분석 기반 1:1 럭셔리 상품 큐레이션

**사용자 스토리**:
- VIP 고객이 홈페이지에 접속하면, 스타일 DNA에 기반한 "Curated for You"
  섹션이 표시된다
- 구매 후 보완 상품 추천, 미탐색 카테고리 발견 제안이 자동 생성된다

**핵심 기능**:
- 고객 스타일 DNA 추출 (구매 70% + 브라우징 30% 가중치)
- 브랜드 친밀도 분석
- 개인화 큐레이션 에디트 (6-12 아이템, 스타일링 노트 포함)
- 크로스셀 / 디스커버리 추천
- VIP 등급별 추천 깊이 차별화

**Agent 매핑**: `vip-profile-analyzer` → `style-recommender` → `luxury-qa-guardian`

### 2.3 F3: 럭셔리 쇼핑 경험 큐레이션 (UC-CUSTOM-02)

**목표**: 브랜드 스토리텔링 + 비주얼 머천다이징으로 프리미엄 경험 제공

**사용자 스토리**:
- 각 브랜드 페이지에서 헤리티지 스토리, 크리에이티브 디렉터 비전,
  시그니처 요소를 에디토리얼 형식으로 확인할 수 있다
- 시즌별 컬렉션 내러티브와 룩북이 자동 생성된다

**핵심 기능**:
- 브랜드 스토리 자동 생성 (헤리티지, 철학, 시그니처)
- 컬렉션 내러티브 (시즌별 스토리라인)
- 룩북 카피 생성
- 에디토리얼 콘텐츠 CMS 연동

**Agent 매핑**: `luxury-content-creator` → `luxury-qa-guardian`

### 2.4 F4: VIP 프로모션 캠페인 (UC-ECOM-04)

**목표**: 등급별 차별화된 럭셔리 프로모션 실행

**사용자 스토리**:
- 마케팅팀이 캠페인 브리프를 입력하면, AI가 등급별 세그먼트/메시지/타임라인을
  자동 설계한다
- Platinum은 Gold보다 48시간 먼저 프리뷰를 받는다

**핵심 기능**:
- VIP 세그먼트 자동 분류 (Platinum / Gold / Silver)
- 등급별 캠페인 콘텐츠 차별화
- 럭셔리 톤 유지 (할인 언어 금지)
- 채널 전략 (이메일, 앱 푸시, SMS)
- 캠페인 성과 KPI 추적

**Agent 매핑**: `vip-profile-analyzer` → `luxury-campaign-manager` → `luxury-qa-guardian`

### 2.5 F5: 고객 리뷰 관리 (UC-ECOM-03)

**목표**: VIP 고객 피드백 즉시 대응 및 인사이트 추출

**사용자 스토리**:
- 고객이 리뷰를 남기면, AI가 감성 분석 후 등급별 맞춤 응답을 초안한다
- 법적 위협/심각한 불만은 즉시 에스컬레이션된다
- 주간 인사이트 리포트가 자동 생성된다

**핵심 기능**:
- 럭셔리 고객 특유의 뉘앙스 감지 (언더스테이트먼트 패턴)
- 등급별 응답 톤 차별화
- 에스컬레이션 자동 분류 (법적, 보안, 인증 이슈)
- 제품/서비스 개선 인사이트 추출

**Agent 매핑**: `review-concierge` → `luxury-qa-guardian`

## 3. Non-AI Features (수동 구현 필요)

### 3.1 고객 계정 & 인증
- 소셜 로그인 (Google, Apple, Kakao)
- VIP 등급 자동 산정 (연간 소비 기준)
- 프로필 관리 (사이즈, 선호도, 위시리스트)

### 3.2 상품 탐색 & 검색
- 패싯 필터 (브랜드, 카테고리, 가격대, 소재, 사이즈, 컬러, 시즌)
- 풀텍스트 검색 + 자동완성
- 비주얼 머천다이징 레이아웃

### 3.3 장바구니 & 결제
- 장바구니 관리
- 다중 결제 수단 (카드, 계좌이체, 카카오페이, 네이버페이)
- 다중 통화 지원 (KRW, USD, EUR, JPY)
- 주문 확인 및 영수증

### 3.4 주문 관리 & 배송
- 주문 상태 추적
- 럭셔리 패키징 옵션
- 반품/교환 프로세스
- 배송 추적 연동

### 3.5 관리자 대시보드
- 상품 관리 (AI 리스팅 승인/수정)
- 주문 관리
- 고객 관리 (VIP 등급, 히스토리)
- 캠페인 관리
- 리뷰 관리 (AI 응답 승인/수정)
- 매출/분석 대시보드

## 4. User Flows

### 4.1 신규 상품 등록 플로우
```
운영팀: 상품 데이터 업로드 (CSV/JSON/수동 입력)
  → AI: 데이터 검증 & 정규화 (luxury-product-curator)
  → AI: 프리미엄 콘텐츠 생성 (luxury-content-creator)
  → AI: QA 검증 (luxury-qa-guardian)
  → [approved] → 운영팀 최종 확인 → 퍼블리시
  → [rejected] → 운영팀에 수정 필요 항목 표시 → 재시도
```

### 4.2 VIP 고객 홈페이지 방문 플로우
```
고객: 로그인 & 홈페이지 접속
  → System: 고객 프로필 로드
  → AI: 스타일 DNA 분석 (vip-profile-analyzer)
  → AI: 개인화 추천 생성 (style-recommender)
  → 홈페이지에 "Curated for You" 섹션 렌더링
  → 고객: 아이템 클릭 → 상품 상세 → 장바구니 → 결제
```

### 4.3 캠페인 실행 플로우
```
마케팅팀: 캠페인 브리프 입력 (테마, 목표, 예산, 기간)
  → AI: 대상 세그먼트 분석 (vip-profile-analyzer)
  → AI: 캠페인 설계 (luxury-campaign-manager)
  → AI: 콘텐츠 QA (luxury-qa-guardian)
  → 마케팅팀: 검토 & 승인
  → System: 스케줄에 따라 발송 (Platinum → Gold → Silver)
```

### 4.4 리뷰 응대 플로우
```
고객: 리뷰 작성
  → AI: 감성 분석 & 응답 초안 (review-concierge)
  → AI: QA 검증 (luxury-qa-guardian)
  → [법적 위협] → 즉시 에스컬레이션 → 법무팀 + CS 관리자
  → [일반] → CS팀 최종 확인 → 응답 게시
  → AI: 인사이트 추출 → 주간 리포트에 반영
```

## 5. Constraints & Assumptions

### 5.1 Constraints
- **팀 규모**: 10명 (개발 6-7, 디자인 1-2, PM 1, QA 1)
- **브랜드 계약**: 모든 브랜드 리스팅은 정식 파트너십 하에서만 가능
- **컨텐츠 정책**: AI 생성 콘텐츠는 반드시 human-in-the-loop 승인 필요
- **개인정보**: VIP 고객 데이터는 국내 개인정보보호법 준수 필수
- **다국어**: MVP는 한국어 + 영어, 이후 일본어/중국어 확장

### 5.2 Assumptions
- 초기 브랜드 파트너 5-10개 확보 후 런칭
- MVP는 웹 우선, 모바일 앱은 Phase 2
- 결제/배송은 기존 PG사/물류사 연동 (자체 구축 X)
- AI 에이전트 팀은 이미 설계 완료 (`.claude/agents/`)

## 7. Risks

| Risk | Impact | Mitigation |
|------|--------|------------|
| AI 콘텐츠 품질 불일치 | 브랜드 이미지 훼손 | QA Guardian + human approval 이중 게이트 |
| 브랜드 파트너 이탈 | 카탈로그 공백 | 계약 SLA + 다각화된 브랜드 포트폴리오 |
| 개인정보 유출 | 법적/신뢰 리스크 | 암호화, 접근 제어, 정기 감사 |
| VIP 이탈 | 매출 집중도 리스크 | 이탈 신호 조기 감지 (profile-analyzer) |
| 경쟁 플랫폼 | 시장 점유율 | AI 개인화 + 에디토리얼 차별화 |
