# PRD Phase 2: Highend Fashion Mall — 미구현 영역 요건 정의

> Phase 1 (Sprint 0-6) 완료 후 식별된 미구현 영역을 기능 요건으로 정의.
> biz-harness 기준 유스케이스 매핑 대상.

---

## 1. 고객 계정 심화 (Account Section)

### F6: 주문 내역 & 배송 추적
**비즈니스 목표**: VIP 고객이 주문 상태를 실시간 확인하고, 배송 추적으로 안심감 제공

**요구사항**:
- 주문 목록 (날짜, 상태, 금액, 아이템)
- 주문 상세 (아이템별 상태, 배송 추적 번호 연동)
- 주문 상태 변경 시 이메일/앱 알림
- 반품/교환 요청 플로우 (사유 선택 → 접수 → 추적)

### F7: 주소록 관리
**비즈니스 목표**: 재구매 시 배송 정보 입력 부담 제거

**요구사항**:
- 다중 배송지 등록/수정/삭제
- 기본 배송지 설정
- 체크아웃 시 저장된 주소 선택

### F8: 스타일 프로필 & 선호도 관리
**비즈니스 목표**: 고객이 명시적으로 취향을 설정하여 AI 추천 정확도 향상

**요구사항**:
- 사이즈 프로필 (상의/하의/신발, 브랜드별 사이즈 메모)
- 선호 브랜드 설정 (추천에 반영)
- 선호 카테고리/소재/컬러 설정
- 알림 채널 선호도 (이메일/SMS/앱)
- 언어 설정 (한국어/영어)

## 2. Admin 인터랙션 완성

### F9: Admin 상품 AI 파이프라인 실행
**비즈니스 목표**: 운영팀이 원클릭으로 AI 상품 리스팅 생성 → 검토 → 승인

**요구사항**:
- 신규 상품 데이터 입력 폼 (브랜드, 이름, 가격, 소재, 이미지 업로드)
- "Generate with AI" 클릭 → API 호출 → 진행 상태 표시
- AI 생성 결과 미리보기 (큐레이션 + 콘텐츠 + QA 스코어)
- 승인/수정/거절 워크플로우
- 수정 시 AI 재생성 트리거
- 상품 상태 관리 (DRAFT → PENDING_REVIEW → PUBLISHED → ARCHIVED)

### F10: Admin 리뷰 AI 워크플로우 실행
**비즈니스 목표**: 리뷰 AI 분석 → 응답 초안 → 승인의 완전한 워크플로우

**요구사항**:
- "Trigger AI Analysis" 클릭 → review-concierge 호출 → 결과 표시
- AI 응답 승인/수정/거절
- 수정 시 인라인 에디터
- 승인 시 리뷰 페이지에 자동 게시
- 에스컬레이션 시 알림 발송 (법적 위협, 인증 이슈)
- 필터 동작 (상태별, 감성별, 등급별)

### F11: Admin 캠페인 AI 생성 + 발송
**비즈니스 목표**: 캠페인 브리프 → AI 설계 → 승인 → 스케줄 발송

**요구사항**:
- 캠페인 브리프 입력 폼 (테마, 목표, 예산, 기간, 대상 등급)
- "Generate with AI" → campaign-manager 호출 → 캠페인 플랜 생성
- 캠페인 콘텐츠 미리보기 (등급별 메시지, 타임라인, KPI 목표)
- 승인 → 스케줄 등록
- 발송 현황 대시보드 (Open/Click/Conversion 실시간)
- 이메일 실제 발송 (Resend 연동)

### F12: Admin 고객 관리 상세
**비즈니스 목표**: VIP 고객 이탈 위험 감지 및 선제 대응

**요구사항**:
- 고객 상세 페이지 (프로필, 구매 이력, 스타일 DNA, 위시리스트)
- 필터 동작 (등급별, 이탈 위험별)
- 이탈 위험 고객 알림
- 고객에게 수동 메시지 발송 기능
- VIP 등급 수동 조정 기능

### F13: Admin 설정
**비즈니스 목표**: 시스템 설정 중앙 관리

**요구사항**:
- 브랜드 캐노니컬 이름 관리 (AI 검증 기준)
- 카테고리 택소노미 관리
- VIP 등급 기준 금액 설정
- AI 에이전트 설정 (모델 선택, 프롬프트 튜닝)
- 이메일 템플릿 관리
- 환율 설정

## 3. 백엔드 연결

### F14: PostgreSQL 연동 + 시드
**비즈니스 목표**: Mock 데이터에서 실제 DB로 전환

**요구사항**:
- Docker Compose로 PostgreSQL + Redis 구성
- Prisma 마이그레이션 실행
- 시드 데이터 투입
- Mock 데이터 레이어 → Prisma 쿼리로 교체
- tRPC 라우터 실제 연결

### F15: 인증 시스템
**비즈니스 목표**: 고객/관리자 인증 및 접근 제어

**요구사항**:
- NextAuth 소셜 로그인 (Google, Kakao)
- 이메일 로그인 (magic link)
- Admin 역할 분리 (admin / super_admin)
- VIP 등급 세션 연동 (하드코딩 제거)
- 미들웨어 admin 접근 제어 실제 구현

### F16: 결제 연동
**비즈니스 목표**: 실제 주문 처리

**요구사항**:
- Toss Payments 연동 (카드, 계좌이체, 간편결제)
- Stripe 연동 (해외 결제)
- 주문 생성 → 결제 처리 → 주문 확인 파이프라인
- 결제 실패 처리 (재시도, 알림)
- 환불 처리

### F17: AI 에이전트 실제 디스패치
**비즈니스 목표**: API 엔드포인트 → 실제 Claude Agent 호출

**요구사항**:
- BullMQ 큐 설정 (Redis-backed)
- Agent SDK 연동 (Claude API)
- 파이프라인 실행: curator → content-creator → qa-guardian
- 에이전트 결과 DB 저장 (AgentJob 테이블)
- Admin에서 실시간 진행 상태 표시 (SSE or polling)
- 에이전트 실패 시 재시도 + 알림

### F18: 검색 엔진
**비즈니스 목표**: 빠르고 정확한 상품 검색

**요구사항**:
- Algolia 인덱스 설정 (상품 동기화)
- 검색 UI (자동완성, 인스턴트 결과)
- 패싯 필터 (브랜드, 카테고리, 가격대, 소재, 사이즈)
- 한국어/영어 형태소 분석

## 4. UX 완성

### F19: 실제 이미지 시스템
**비즈니스 목표**: 럭셔리 수준의 상품 이미지 제공

**요구사항**:
- S3 + CloudFront 이미지 파이프라인
- Next/Image 최적화 (AVIF/WebP, 반응형)
- 상품 이미지 갤러리 (줌, 스와이프)
- Placeholder shimmer 로딩 상태

### F20: 리뷰 작성 완성
**비즈니스 목표**: 고객이 실제로 리뷰를 남길 수 있는 완전한 플로우

**요구사항**:
- 별점 선택 인터랙션 (클릭으로 실제 반영)
- 리뷰 텍스트 검증 (최소 20자)
- 리뷰 제출 → API → DB 저장
- 구매한 상품에만 리뷰 가능 (인증)

### F21: 알림 시스템
**비즈니스 목표**: 고객에게 적시에 관련 정보 전달

**요구사항**:
- 이메일 알림 (Resend): 주문 확인, 배송 상태, 리뷰 응답, 캠페인
- 앱 내 알림 센터 (헤더 벨 아이콘)
- 알림 읽음/안읽음 상태
- 고객별 알림 채널 선호도 반영
